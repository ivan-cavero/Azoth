# Meaning card

Also load `protocols`.

Edit one row of `research/atlas/meanings.md`.

The row states the plain name, why the server sends it, each named field, each unknown field with an id, the client SHA-256, and the evidence word: measured, partial, or unknown.

A model guess stays a candidate until a second signal agrees. Do not paste a byte string in place of a name. If the row is still unknown, Rust does not encode it. Say that in the row.
