# Competency questions

The ontology is healthy when agents can answer these from indexes + concept
files without reading STATUS novels.

1. What messages make peer A visible to peer B?
2. Who is authority for position, inventory, currency, and combat HP?
3. What happens if message X is omitted for 30 seconds?
4. Which public API fields are safe vs admin-only / privacy-gated?
5. Which admin commands update a live session vs only the database?
6. Which crate/module implements this concept today?
7. What is the next experiment that would raise confidence for concept U?
8. Which build SHA-256 do these VAs/layouts apply to?
